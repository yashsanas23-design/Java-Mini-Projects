# 🐍 Snake Game

A classic Snake Game built using **Java Swing** as a hands-on project to practice Java fundamentals, GUI development, and game logic.

## Features

* Keyboard-controlled snake movement
* Food collection and score tracking
* Snake growth after eating food
* Collision detection
* Pause and resume *(if implemented)*
* Restart functionality *(if implemented)*

## Tech Stack

* Java
* Java Swing
* IntelliJ IDEA

## Controls

* `↑ ↓ ← →` — Move the snake
* `Space` — Pause / Resume *(if implemented)*
* `Enter` — Restart *(if implemented)*

## Run

1. Open the `SNAKE_GAME` folder in IntelliJ IDEA.
2. Navigate to `src/Snakegame.java`.
3. Run the `main()` method.
